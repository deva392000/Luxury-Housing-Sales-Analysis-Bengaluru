# Luxury Housing Sales Analysis – Bengaluru
## Project Overview

This project analyzes luxury housing sales in Bengaluru to identify market trends, buyer preferences, property demand, developer performance, and transaction patterns.

The project uses Python for data cleaning and feature engineering, SQL for data analysis, and Power BI for interactive dashboard development and business insights.
## Project Objectives

- Analyze luxury housing sales trends in Bengaluru.
- Identify high-performing micro-markets.
- Understand buyer preferences and popular configurations.
- Analyze developer and project performance.
- Evaluate booking and transaction patterns.
- Identify key business insights from the housing sales data.
- Build an interactive Power BI dashboard for business decision-making.
## Tools & Technologies

- **Pandas & NumPy** – Data manipulation and transformation
- **SQL Server** – Data storage and SQL analysis

## Power BI Dashboard

The Power BI dashboard provides an interactive view of the Bengaluru luxury housing market.

### Dashboard Features

- Key Performance Indicator (KPI) cards
- Interactive filters
- Micro-market analysis
- Configuration analysis
- Developer performance analysis
- Booking and transaction analysis
- Buyer preference analysis
- Ticket price analysis
- Business insights and recommendations

The dashboard consists of three analytical pages designed to support business decision-making.
## Key Business Insights

- **Market Insight:** Kanakapura Road recorded the highest booking conversion rate at approximately 51%, indicating strong booking performance in this micro-market.
- **Configuration Insight:** 3 BHK was the most preferred configuration, accounting for approximately 33.64% of total demand.
- **Transaction Insight:** Booking and transaction patterns helped identify areas with stronger customer demand.
- **Developer Insight:** Developer-level analysis helped compare project performance and identify stronger-performing developers.
- **Pricing Insight:** Ticket price analysis provided insights into luxury housing price patterns across Bengaluru micro-markets.
- **Buyer Insight:** Buyer-type analysis helped understand different customer segments and their contribution to housing demand.
## Recommendations

- Focus on high-performing micro-markets with strong booking demand.
- Give more attention to popular configurations such as 3 BHK.
- Monitor developer performance to identify successful projects.
- Use pricing and buyer insights to improve sales strategies.
- Use the Power BI dashboard for regular market monitoring and decision-making.
